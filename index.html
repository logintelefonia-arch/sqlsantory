GUIA RÁPIDO

Como usar o Santory Tec

Escolha um módulo para ver o que cada botão faz e o fluxo recomendado.

♙ClientesCadastro e identificação＋
  1. Clique em + Novo cliente, preencha nome e contatos e use Gerar ID para criar um identificador único aleatório. E-mail é opcional.
  2. Use a busca para localizar por nome, ID, telefone, WhatsApp ou endereço.
  3. Histórico abre os orçamentos, ordens e movimentações vinculados ao cliente; Editar altera o cadastro; × exclui o registro.
  4. O histórico é preenchido pelo sistema quando você cria registros vinculados ao cliente.
▤OrçamentosPropostas, aprovação e pagamento＋
  1. + Novo orçamento abre o editor antigo dentro do sistema. Selecione um cliente cadastrado para trazer os dados.
  2. Adicione produtos/serviços do catálogo ou linhas manuais; confira quantidades, valores, condições e validade antes de salvar.
  3. Abrir / PDF abre a proposta para imprimir ou salvar em PDF. Mais ações reúne duplicar, ver versões, enviar resumo no WhatsApp, aprovar, encerrar ou registrar pagamento, conforme o status.
  4. Ao aprovar, informe data e forma de aprovação. Em seguida, use Criar OS para abrir um atendimento vinculado.
  5. Ao registrar pagamento, o sistema fecha o orçamento e cria a entrada correspondente no financeiro. Propostas expiradas e encerradas continuam no histórico.
▣Ordens de serviçoAtendimento e equipamento＋
  1. Clique em + Nova ordem de serviço, escolha o cliente e preencha equipamento, defeito, diagnóstico, serviços, peças e datas.
  2. Use Adicionar fotos para anexar até três imagens do equipamento. Remova cada foto pelo botão × antes de salvar, se necessário.
  3. Salvar cria ou atualiza a OS. Use Avançar etapa para atualizar o andamento; a aprovação do orçamento vinculado libera a execução.
  4. Na lista, Editar altera o atendimento, PDF imprime a ordem, Gerar orçamento cria proposta vinculada e Financeiro prepara um lançamento revisável.
R$FinanceiroReceitas, despesas e caixa＋
  1. Clique em + Novo lançamento, escolha receita ou despesa, valor, data, status, categoria e, se desejar, cliente.
  2. Use os filtros de ano, mês e período para analisar os gráficos e totais.
  3. Em lançamentos pendentes, Receber ou Pagar registra a baixa. Orçamentos pagos entram automaticamente como receita.
  4. Edite ou exclua lançamentos individualmente na própria linha.
▦Montador de PCsComponentes, preço e compatibilidade＋
  1. Cadastre componentes em + Cadastrar componente, incluindo categoria, custo, preço e especificações técnicas.
  2. Use Adicionar à montagem nos componentes ou Adicionar item avulso. Ajuste quantidade e valores na configuração.
  3. Informe o cliente se quiser vincular o orçamento. Confira compatibilidade e resumo de custo, venda e margem.
  4. Imprimir / PDF gera uma cópia da montagem; Limpar montagem inicia outra.
▧CatálogoItens reutilizáveis nos orçamentos＋
  1. Clique em + Novo produto ou serviço e informe nome, tipo, categoria e preço. Custo interno e estoque são opcionais.
  2. Marque Disponível para orçamento para permitir inserir o item no editor.
  3. Use busca e filtros para localizar itens; edite ou exclua cada registro individualmente.
✎AnotaçõesNotas salvas no navegador＋
  1. Nova anotação
  2. Informe título e descrição e clique em Salvar anotação. Para alterar, abra uma anotação, edite e salve.
  3. Use o alfinete, a busca e o filtro de data para organizar. O botão de excluir remove somente a nota escolhida.
⇩DownloadsInstaladores e utilitários＋
  1. Use Cadastrar programa para incluir nome, descrição, versão, categoria e link ou arquivo de download.
  2. Pesquise, filtre por categoria e use editar ou excluir na linha do programa. Abrir link inicia o download no navegador.
▤RelatóriosHistórico e documentos técnicos＋
  1. Use filtros de cliente, tipo, status e período para consultar ordens, orçamentos e financeiro.
  2. Exportar planilhaImprimir / PDF
  3. Na área de formulários técnicos, escolha o tipo de relatório e selecione o cliente/ID no próprio formulário antes de preencher.

  1. Exportar arquivo JSON
  2. No outro dispositivo, abra o sistema e use Selecionar arquivo JSON para importar a cópia.
